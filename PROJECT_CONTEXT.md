# Piano Auction Platform

Project Type:
Luxury piano auction platform inspired by Piano Auctions UK.

Goal:
Build an MVP auction platform in 7 days.

Stack:

* Laravel 12 backend
* React frontend
* Tailwind CSS
* Filament admin panel
* Sanctum authentication
* Laravel Reverb realtime bidding

Core Features:

* Online live bidding
* Telephone bidding
* Absentee bidding
* Sell My Piano forms
* Value My Piano forms
* Auction catalogue
* Realtime bid updates

Architecture:

* API-first backend
* React frontend consuming APIs
* Modular Laravel architecture

Important:

* Keep code modular
* Avoid overengineering
* Use services for business logic
* Optimize for rapid development
