# Piano Auction Platform

Project Type:
Luxury piano auction platform inspired by https://pianoauctions.co.uk/

Tech Stack:
- Laravel 11
- React
- Tailwind CSS
- Filament Admin
- Sanctum Auth
- Laravel Reverb

Rules:

- Follow Piano Auctions UK design style
- Luxury premium appearance
- Black, white, gold color palette
- Full-width layouts
- Responsive design
- Desktop-first UI
- Use Tailwind CSS only
- Avoid unnecessary dependencies
- Component-based architecture
- API-first Laravel backend
- Clean and reusable code
- Use services for business logic
- Use Laravel Reverb for realtime bidding
- Use Sanctum authentication
- Verify user email before bidding
- Optimize for MVP delivery in 7 days

Design Principles:

- Elegant typography
- Large hero sections
- High-quality piano imagery
- Spacious layouts
- Premium auction-house aesthetic
- Smooth hover animations
- Dropdown navigation
- Luxury card designs
