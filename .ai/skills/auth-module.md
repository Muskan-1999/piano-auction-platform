# Authentication Module

Requirements:

* Laravel Sanctum authentication
* Register API
* Login API
* Logout API
* Reset Password API
* Current user endpoint
* Password hashing
* Validation using Form Requests

User Fields:

* name
* email
* phone
* address
* password
* role

Roles:

* admin
* bidder
* user

Routes:

* /api/register
* /api/login
* /api/logout
* /api/reset-password
* /api/user
