# Laravel Backend Standards

Rules:

* Use Laravel 11
* Use API-first architecture
* Use Sanctum authentication
* Use Filament admin panel
* Use Reverb for realtime events
* Use service classes for business logic
* Use Form Requests for validation
* Use API Resources
* Keep controllers thin
* Use eager loading
* Use RESTful APIs
* Use modular architecture
* Avoid duplicated logic
* Optimize for MVP speed
* Middleware for unauthorized user login

Folder Structure:

* Models
* Controllers/API
* Services
* Events
* Requests
* Resources

Database:

* Use migrations
* Use proper relationships
* Use nullable foreign keys when needed
